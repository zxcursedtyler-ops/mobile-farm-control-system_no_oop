# 📱 Mobile Farm Control System

Распределенная система автоматизации и управления фермой Android-устройств. 
Проект предназначен для централизованной выдачи задач мобильным устройствам (через Termux / ADB), автоматической ротации прокси, отслеживания телеметрии устройств и управления очередью процессов через GUI.

---

## 🛠 Технологический стек

* **Server:** Python, FastAPI, SQLite, Loguru
* **Client (Mobile):** Python, Termux API, ADB (Android Debug Bridge), ThreadPoolExecutor
* **Desktop GUI:** CustomTkinter, Requests, Multithreading
* **Automation & Anti-Fraud:** Алгоритмы имитации человеческого поведения (кривые Безье, генерация реалистичных задержек и учетных данных)

✨ Ключевые возможности
Централизованный REST API Сервер:

Распределение очереди задач между подключенными устройствами.

Сбор метрик устройств (уровень заряда, статус, активность).

Автоматическая архивация и агрегация логов.

Клиентская часть (Android / Termux):

Многопоточная обработка задач.

Периодическая отправка телеметрии и проверки связи с сервером (Heartbeat).

Десктопный интерфейс управления:

Мониторинг статусов устройств в реальном времени.

Просмотр очереди задач и динамической статистики.

Удаленный просмотр логов с устройств.

Модули автоматизации:

Имитация движений пальца по кривым Безье с генерацией инерции.

Генерирование стойких паролей на основе паттернов пользователей.

🚀 Быстрый запуск
1. Запуск сервера
Bash
cd server
pip install -r requirements.txt
uvicorn api:app --host 0.0.0.0 --port 8000
2. Запуск GUI менеджера
Bash
cd desktop_gui
python main_gui.py
3. Запуск клиента на Android
Bash
python client.py
